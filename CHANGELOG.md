# Changelog

## 1.0.0 — 2026-08-20

- единый GitHub bootstrap для свежей Ubuntu VM;
- поддержка Ubuntu 22.04/24.04;
- интерактивная базовая защита VM;
- SSH key onboarding и безопасная смена порта;
- GitLab, Runner, web, PLANKA, telemetry, fileserver, Nextcloud, Mailcow, monitoring, edge, Vaultwarden и SFTPGo roles;
- добавлена лёгкая `mail-lite` роль для маломощных Proxmox-хостов;
- migration-kit перенесён в тот же репозиторий;
- CI и локальный verify script.
